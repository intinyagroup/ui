Image editor with filters and effects for Intinya UI — crop, rotate, and a filter/effect pipeline.

## Install

```bash
npm install @intinyagroup/image-editor
```

## Usage

```svelte
<script>
  import { ImageEditor } from '@intinyagroup/image-editor';
</script>

<ImageEditor src="/photo.jpg" />
```
