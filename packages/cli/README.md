# @intinyagroup/cli

[![npm version](https://img.shields.io/npm/v/@intinyagroup/cli?style=flat-square&color=7c3aed)](https://www.npmjs.com/package/@intinyagroup/cli)
[![Docs](https://img.shields.io/badge/docs-ui.intinya.id-7c3aed?style=flat-square&labelColor=1a1a1a)](https://ui.intinya.id)
[![License MIT](https://img.shields.io/npm/l/@intinyagroup/cli?style=flat-square&color=7c3aed)](https://github.com/intinyagroup/ui/blob/main/LICENSE)


CLI to add Intinya UI components to your Svelte project — `add`, `init`, `update`, `doctor`, and `list` commands.

## Install

```bash
npm install -g @intinyagroup/cli
# or run without installing:
npx @intinyagroup/cli
```

## Usage

```bash
npx @intinyagroup/cli init        # Setup project (tokens, cn(), components.json)
npx @intinyagroup/cli add button  # Copy component (or --mode npm)
npx @intinyagroup/cli update      # Update installed components
npx @intinyagroup/cli doctor      # Check setup health
npx @intinyagroup/cli list        # Browse components by category
```
